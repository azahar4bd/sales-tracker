# সেলস ট্র্যাকার - Sales Tracker

ক্রয় • বিক্রয় • খরচ • রিপোর্ট — এক জায়গায়

একটি সিম্পল কিন্তু শক্তিশালী সেলস ট্র্যাকার ওয়েব অ্যাপ।

## ✨ ফিচার

### 📝 এন্ট্রি পেজ
- **তারিখ** নির্বাচন
- **ক্যাটাগরি** dropdown (ক্রয় / বিক্রয়) + নতুন ক্যাটাগরি Add (+ বাটন)
- **আইটেম** dropdown (৫ এর বস্তা, ১০ এর বস্তা) + নতুন আইটেম Add
- **হতে / দোকানের নাম** — ক্যাটাগরি অনুযায়ী লেবেল অটো চেঞ্জ
  - ক্রয় → "হতে"
  - বিক্রয় → "দোকানের নাম"
- **বিক্রয়কারী** — শুধু বিক্রয় সিলেক্ট করলে দেখা যায় + নতুন নাম Add
- **পরিমাণ, একক মূল্য, মোট মূল্য** (অটো হিসাব: পরিমাণ × একক মূল্য)
- **খরচ বিবরণ + খরচ পরিমাণ**
- **স্থিতি** (পরিশোধিত / বাকি / আংশিক)
- Save / Reset বাটন
- নিচে টেবিল — সার্চ, ফিল্টার, প্রতিটি এন্ট্রিতে Edit / Delete

### 📈 রিপোর্ট পেজ
- তারিখ, ক্যাটাগরি, আইটেম দিয়ে ফিল্টার
- ৪টি সামারি কার্ড: মোট বিক্রয়, মোট ক্রয়, মোট খরচ, নিট লাভ/ক্ষতি
- বার চার্ট (শেষ ৬ মাস)
- ডোনাট চার্ট (স্থিতি অনুযায়ী)
- ক্যাটাগরি wise সামারি
- বিস্তারিত রিপোর্ট টেবিল
- Excel (CSV) Export + Print

## 🚀 ব্যবহার
1. `index.html` ফাইলটি ব্রাউজারে ওপেন করুন
2. ডেটা ব্রাউজারের LocalStorage এ সেভ থাকে
3. GitHub Pages চালু করতে: Settings → Pages → Deploy from main branch

## 🛠 টেক
- Pure HTML / CSS / JavaScript
- No framework, No backend
- LocalStorage
